## Mark as Read

Send a read receipt for a specific message:

```ts
await zap.api.send.markAsRead("wamid.HBgLNTUxMTk...");
```

Read receipts don't require the 24-hour message window.

## Reactions

Send an emoji reaction to a message:

```ts
await zap.api.send.reaction("+5511999998888", "wamid.HBgLNTUxMTk...", "👍");
```

To remove a reaction, pass an empty string:

```ts
await zap.api.send.reaction("+5511999998888", "wamid.HBgLNTUxMTk...", "");
```

## Typing Indicator

Show a typing indicator (composing bubble) to let the user know you're processing their message. It is available inside webhook hooks as `ctx.api.typingIndicator(messageId, action?)`:

- `messageId` is the ID of the message you are answering.
- `action` is `"typing_on"` (the default) or `"typing_off"`.

The typing indicator disappears after 25 seconds or when you send a message. This is useful for bot flows where processing takes a moment:

```ts
webhook: {
  onMessage: async (ctx) => {
    // Show typing while we process
    await ctx.api.typingIndicator(ctx.message.id);

    const reply = await generateBotReply(ctx.content);
    await ctx.api.sendText(ctx.phone, reply);
  },
}
```

## Response Format

All send methods return a `SendResult`:

```ts
interface SendResult {
  success: boolean;
  messageId?: string;  // Meta's message ID, on success
  error?: string;
  errorCode?: number;  // Meta's error code
  code?: string;       // Better Zap's code, e.g. "CONTEXT_WINDOW_CLOSED"
  httpStatus?: number;
  details?: Record<string, any>;
}
```

A failed send is returned as `{ success: false, ... }` instead of throwing, so check `success`.

In development mode (`environment: "development"`), mock responses are returned without calling the Meta API.
